# Privacy Policy

**PeripheralBattery does not collect, transmit, or sell any user data.**

- The application runs entirely locally on your computer.
- It does not contain telemetry, analytics, crash reporting, or auto-update network calls.
- It does not access the network at all.
- Battery data is read from local HID / Bluetooth / XInput APIs and only displayed to you.
- Configuration and logs are stored locally under %APPDATA%\PeripheralBattery\
  (or a data folder next to the executable when APPDATA is not writable).
- Logs contain device names and battery readings; they never leave your machine unless you
  choose to copy/paste the diagnostic report yourself.

If you have questions, open an issue at
<https://github.com/KaBanei/peripheral-battery/issues>.
