# v1.8.0 — 极简侧边电量条 + 透明度

Windows 托盘电量工具：显示 2.4G / 蓝牙外设（鼠标、键盘、耳机、手柄）的实时电量。
本版本聚焦最小化后的“侧边电量条”体验。

## 下载

- **2.4G外设电量监控-v1.8.0.zip**
- SHA256：`8CD4EF6353EB17097215770311A10881276FD901A8AE11D694CBC0584923614C`

## 本版亮点

- **极简浮窗**：最小化后贴屏幕边缘，不显示文字，只用纵向色条表示每台设备电量（绿/黄/红/蓝）。
- **透明度可调**：设置 → 常规 → 浮窗透明度，20–100%（默认 100%）。
- **拖动吸附**：浮窗可拖动，松手吸附到最近屏幕的左/右边缘，并记住位置。
- **自动避让**：前台窗口全屏或最大化时自动隐藏，恢复正常窗口后自动出现。
- **窗口可缩放**：主面板拖动任意边缘调整大小，列表与状态区自适应。

## 自 v1.3.1 以来的主要变化

- v1.4.0：主窗口自由缩放；最小化侧边电量条。
- v1.5.0：浮窗拖动吸附、位置记忆。
- v1.6.0：移除托盘图标模式；浮窗缩小；最大化/全屏自动隐藏。
- v1.7.0：去掉浮窗文字，改为极简电量色条（约 22px 宽）。
- v1.8.0：浮窗透明度 20–100% 可调。

## 安装

1. 解压 zip；
2. 双击 `PeripheralBattery.exe`；
3. 首次启动点“开始使用”，托盘出现电池图标；
4. 左键托盘打开悬浮面板，双击打开主面板。

要求：Windows 10/11 x64，.NET Framework 4.8（系统自带）。
exe 暂未签名，SmartScreen 提示时点“更多信息 → 仍要运行”，或先运行 `unblock.ps1`。

## 已知限制

- VGN 鼠标/键盘为实验性支持，设备休眠时可能短暂显示“未知”。
- 其它品牌需要按 `docs/generic-method.md` 抓包后添加协议表。
- 本版本尚未代码签名；SignPath 开源签名通过后会发布签名版本。

## English

A lightweight Windows tray battery monitor for 2.4G / Bluetooth peripherals.
v1.8.0 adds an ultra-minimal textless edge bar with adjustable opacity (20–100%),
drag-to-snap positioning, auto-hide for maximized/fullscreen windows, and a
freely resizable main window. MIT licensed; no drivers, no telemetry, no network.
