# v1.8.4 — 开机自启显示浮窗 + 2.4G 耳机识别

Windows 托盘电量工具：显示 2.4G / 蓝牙外设（鼠标、键盘、耳机、手柄）的实时电量。

## 下载

- **2.4G外设电量监控-v1.8.4.zip**
- SHA256：`439BE7988B9FE40EE1930AEF410C5A6E365CA00850408A7B401D66090BD7403B`

## 本版亮点

- **开机自启动默认显示侧边浮窗**：登录后不再只留托盘图标，右侧电量条直接出现。
- **识别 2.4G 耳机**：新增音频 dongle 判断，花再 Halo Space D1（2D99:E049）会显示为“耳机 / 2.4G”。
- **设备按类别排序**：鼠标 → 键盘 → 耳机 → 手柄 → 其它，未读电量的耳机不会被手机挤到列表底部。
- **开机启动更可靠**：兼容任务管理器“禁用”写入的 StartupApproved 标记；保存失败会弹窗；附 `tools/enable-autostart.ps1` 修复脚本。

## 自 v1.8.0 以来的变化

- v1.8.1：开机启动修复（StartupApproved、失败提示、诊断日志、修复脚本）。
- v1.8.2：通用识别支持 2.4G 音频 dongle（EDIFIER 花再 Halo Space D1）。
- v1.8.3：设备列表按类别排序，耳机条目默认可见。
- v1.8.4：`--tray` 自启动默认显示侧边浮窗。
- 另：`tools/package-release.ps1` 打包时只保留最新版 dist 产物。

## 安装

1. 解压 zip；
2. 双击 `PeripheralBattery.exe`；
3. 首次启动点“开始使用”；
4. 设置 → 启动 → 勾选“随 Windows 启动”。

要求：Windows 10/11 x64，.NET Framework 4.8（系统自带）。
exe 暂未签名，SmartScreen 提示时点“更多信息 → 仍要运行”，或先运行 `unblock.ps1`。

## 已知限制

- 花再 Halo Space D1 的厂商 HID（FF13/FF14）没有公开电量命令，耳机条目显示“未知电量”；其它设备不受影响。
- VGN 鼠标/键盘为实验性支持，设备休眠时可能短暂显示“未知”。
- 本版本尚未代码签名；SignPath 开源签名通过后会发布签名版本。

## English

A lightweight Windows tray battery monitor for 2.4G / Bluetooth peripherals.
v1.8.4 shows the minimal edge bar on autostart, recognizes 2.4G audio dongles as
headsets, sorts devices by kind, and improves Windows autostart reliability.
MIT licensed; no drivers, no telemetry, no network access.
